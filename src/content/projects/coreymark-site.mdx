## Why this project exists

A credibility anchor that also doubles as a public case study. The site needed to be cheap to run, fast to ship, easy to update from a Markdown drafting workflow, and honest about how it was built — including the parts AI got wrong.

## What it is

A static site generated by Astro, deployed from GitHub to Azure Static Web Apps via GitHub Actions, fronted by Cloudflare for DNS, analytics, and proxying. Infrastructure lives in Terraform; content lives in MDX content collections (`blog`, `projects`, `now`). Blog posts get auto-generated tables of contents, a reading-progress bar, code-copy buttons, and a reading-time estimate. Every PR spins up its own Azure preview URL.

## The guardrails

- **$0/month at rest.** Free tiers the whole way down — ASWA Free, Cloudflare Free, GitHub Actions free minutes. Moves to Standard only when a feature needs it.
- **Lighthouse ≥ 90 across all four categories** on desktop and mobile. Mobile scores perfect 100s on accessibility, best practices, and SEO.
- **IaC-first.** Nothing touches the Azure portal for routine work. Tenant, resource group, static web app, and custom domains are all in Terraform.
- **Issue-driven workflow.** GitHub Issues with a 17-label taxonomy (type/priority/area/status), regression tests in Playwright, no direct commits to `main`.
